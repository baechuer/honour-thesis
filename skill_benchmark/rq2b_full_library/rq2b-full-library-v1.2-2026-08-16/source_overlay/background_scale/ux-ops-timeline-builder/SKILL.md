# Ux Ops Timeline Builder

## Use when

- The user wants sequence reconstruction or schedule structure from user interview notes, usability findings, design brief, prototype feedback.

## Input and preconditions

- The source contains dates, order cues, event descriptions, or dependency markers.
- Relevant material: user interview notes, usability findings, design brief, prototype feedback.

## Dependencies and resources

- research notes
- participant context
- prototype
- design goals
- task-specific constraints

## Procedure

1. Extract dated events, ordering cues, dependencies, and unresolved timing gaps.
2. Place events in chronological order without inventing missing dates.
3. Flag conflicts, dependencies, and uncertain sequence points.
4. Return the dated timeline and gap list.

## Output

Timeline with dates, event descriptions, dependencies, and unresolved gaps.
