# Partnerships Ops Evidence Grounder

## Use when

- The user wants claims checked against partner proposal, MOU draft, co-marketing plan, partner report rather than rewritten or summarized.

## Input and preconditions

- Source material is available and claims can be linked to evidence spans.
- Relevant material: partner proposal, MOU draft, co-marketing plan, partner report.

## Dependencies and resources

- partner profile
- proposal terms
- shared goals
- approval process
- task-specific constraints

## Procedure

1. List the claims that require evidence.
2. Match each claim to the most relevant source passage or record.
3. Classify support as direct, partial, unsupported, or uncertain.
4. Return the claim-evidence map with limitations.

## Output

Claim-evidence map with supported, unsupported, and uncertain claims.
