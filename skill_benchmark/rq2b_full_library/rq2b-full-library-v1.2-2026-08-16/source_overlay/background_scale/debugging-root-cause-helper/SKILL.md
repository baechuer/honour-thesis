# Debugging Root Cause Helper

## Use when

- The user has a bug symptom and wants cause analysis rather than a review of possible risks.

## Input and preconditions

- The required task material and expected output are available.

## Output

Root-cause hypothesis, evidence, reproduction notes, and targeted fix direction.
