# RQ2b-NC V7 Machine B coordinator-context gate

Eight independently validated coordinator returns in Microbatch 002 correctly
returned `REOPEN_PACKET`. The sealed coordinator packet provides a fresh
source-visible candidate and the two assessments, but not the task prompt or
task-specific material requirements needed to resolve an adequacy disagreement
without inference.

This opens a method gate for all coordinator-dependent closure. It does not
alter the frozen V7 library and does not invalidate the provenance of existing
artifacts; it prevents their use as final-library evidence until a method
decision supplies a hash-bound coordinator context and affected packets are
reviewed again. Independent target-blind A/B data collection can remain
separate and continues to be non-retrieval evidence.
