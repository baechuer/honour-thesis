# RQ2b-NC V7 Machine B initial-review microbatch 003

The assigned twelve unstarted Machine B groups are selected in the continuing
ascending SHA-256(`batch_id`) order. Every group is one intact V7 packet: six
sealed main candidates plus two sealed tails. Reviewer A and Reviewer B each
receive the corresponding target-blind render and must return independent
eight-candidate assessments.

Reviewers must use only their lane's assignment and render plus the frozen V7
rubric. They must not inspect peer returns, opaque joins, targets, main/tail
roles, provenance, retrieval/reranking outputs, or metrics. The rendered
review inputs are reproducible and intentionally excluded from Git; their
file hashes are bound in the assignments.
