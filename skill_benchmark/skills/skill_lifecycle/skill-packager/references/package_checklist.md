# Skill Package Checklist

Use this reference only after the skill packager skill is selected.

Check:

- `SKILL.md` exists at the skill root.
- Frontmatter has `name` and `description`.
- Description states when to use the skill.
- Resource links point to existing files.
- Scripts are executable or clearly invoked.
- Large references are not duplicated in `SKILL.md`.
- Unrelated notes, scratch files, and generated outputs are removed.
- License or source attribution is preserved when applicable.
