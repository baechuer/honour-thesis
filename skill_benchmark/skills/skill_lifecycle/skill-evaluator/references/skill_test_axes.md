# Skill Test Axes

Use this reference only after the skill evaluator skill is selected.

Evaluate:

- Trigger fit: whether the skill should activate for the task.
- Boundary fit: whether a neighboring skill would be more appropriate.
- Workflow fit: whether the body gives enough procedural guidance.
- Output fit: whether the result matches the expected artifact.
- Resource fit: whether referenced scripts or files are discoverable and relevant.
- Failure handling: whether the skill handles missing inputs, ambiguity, or unsupported cases.

Keep selection failure and execution failure separate in the evaluation notes.
