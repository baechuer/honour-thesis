# Airtable Workflow Automator

Automates work inside Airtable rather than spreadsheets or Notion.

## Use when

- The user has an Airtable workflow or wants a base automation.
- Fields, views, triggers, and integrations matter.

## Not for

- Building Excel formulas.
- Creating Notion research databases.
- Scheduling meetings.

## Preconditions

- Airtable workspace/base context exists.
- Trigger and desired automation action are known.

## Workflow

1. Map records, fields, and views.
2. Define trigger conditions.
3. Plan automation actions and integrations.
4. Return setup checklist.

## Writing rules

- Do not assume spreadsheet formulas transfer directly.
- Keep trigger conditions precise.

## Default shape

- Base/fields
- Views
- Automation trigger
- Actions/tests
