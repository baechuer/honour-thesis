# Implicit Browser Flow Investigator

Use this routine when the story is an interaction that breaks. The path normally starts with opening the target page, reproducing the user's clicks, collecting console and network evidence, and deciding whether the failure is selector, timing, state, data, or app logic. The output is a reproduction trace and fix hypothesis, not a visual design review.
