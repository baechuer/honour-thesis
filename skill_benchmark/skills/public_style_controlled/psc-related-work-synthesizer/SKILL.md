# Related Work Synthesizer

This is a public-style controlled skill used for retrieval evaluation. It is written as a practical capability note rather than a neat benchmark schema.

Cluster intent: Research reading tasks where summary, method extraction, citation grounding, and synthesis share academic language.

## When to use

Use when there are multiple sources and the output should connect them into a research narrative.

## Requirements

- Two or more sources
- Need for thematic comparison and gap framing

## Instructions

- Group approaches by theme.
- Compare assumptions and evidence.
- Identify tensions and gaps.
- Write positioning notes.

## Deliverables

- Related-work synthesis
- Theme comparison
- Gap statement

## When not to use

Not for single-paper method extraction or claim-level citation checking.

## External dependencies to preserve

- Multiple source notes

## Example use

A good request names the artifact or situation, gives enough operational context to choose this capability, and asks for the deliverable above.
