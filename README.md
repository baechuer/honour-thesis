# Honour Thesis

Working repository for the honours thesis on agent skill retrieval and representation.

This repository tracks thesis notes, LaTeX drafts, presentation material, and pointers to the supporting code repositories used during the project.

## Structure

- `thesis_notes/`: research notes, progress trackers, experiment summaries, and planning documents.
- `thesis_latex/`: thesis writing scaffold and LaTeX sources.
- `skill_benchmark/`: benchmark and experiment code for skill retrieval evaluation.
- `nanobot/`: agent system code used as context for the thesis work.

`skill_benchmark` is tracked directly in this thesis repository because it is the core experimental artifact. `nanobot` is tracked as a Git submodule so its independent history is preserved.
