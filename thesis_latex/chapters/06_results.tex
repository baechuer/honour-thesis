\section{Low-Information Stress Test}

A separate low-information prompt set was used to check whether schema reranking depends on explicit procedural cues. Performance drops sharply across methods. The best strict top-1 score is currently 41.7\% for MiniLM full-skill embedding. Qwen full-skill retrieval plus local schema reranking reaches 25.0\% top-1 and 66.7\% top-5.

This suggests that schema reranking is not secretly inferring hidden intent. It works best when the request contains enough procedural evidence to match structured fields. Very underspecified requests may require a query-understanding or clarification step before retrieval.

\section{Failure Mode Analysis}

The strongest current method has 10 strict top-1 failures out of 67 prompts. Four failures are first-stage exclusions where Qwen does not place the gold skill in the top-100. Six failures are reranker, boundary, negation, meta-skill, or annotation issues.

The main failure types are:

\begin{itemize}
  \item first-stage embedding confuses task object with required procedure;
  \item schema reranking overweights secondary terms;
  \item negative usage boundaries are too weak;
  \item meta-skill tasks such as editing or evaluating a skill are confused with using the named skill;
  \item some domain-specific competitors may require acceptable-alternative adjudication;
  \item underspecified prompts create genuine ambiguity.
\end{itemize}
