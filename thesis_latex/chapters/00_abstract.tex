\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Large language model agents increasingly rely on reusable skills: procedural capability units that may package instructions, workflow steps, scripts, examples, resources, dependencies, and constraints. As skill libraries scale, the central difficulty is not only storing many capabilities, but selecting the right capability when multiple skills appear semantically similar. A request about extracting information from a PDF, for example, may plausibly match skills for layout review, summarisation, citation grounding, field extraction, OCR, or format conversion, even though these skills require different procedures.

This thesis investigates what information agent skill representations must preserve to distinguish semantically similar but procedurally distinct skills at scale. It separates three layers that are often conflated: the stored skill artifact, the selection representation exposed to a retriever, and the retrieval policy that produces a candidate set before the main agent loads full skill documentation. The thesis evaluates flat metadata, full skill artifacts, extracted procedural fields, dependency/resource-aware fields, dense retrieval, generic neural reranking, SkillRouter-style skill-specific retrieval, deterministic procedural reranking, and planned tree/graph structure-aware retrieval.

The current benchmark contains 2401 skills, including 137 controlled evaluated skills, 1800 generated background-scale skills, 460 imported public skills, and 4 support skills. It includes 137 controlled prompts plus a separate 32-prompt public-gold validation stratum. Validation checks cover integrity, procedural alignment, semantic confusability, prompt leakage, scale pressure, public-skill field prevalence, and gold-label stability. Current results show that flat metadata and generic full-skill embedding alone remain fragile under scale. SkillRouter's released skill-specific embedding and reranker provide a strong baseline, reaching 83.2\% top-1 on controlled prompts. Combining SkillRouter embedding with the thesis field-aware reranker reaches 86.9\% top-1 and 0.927 MRR on the controlled benchmark, but does not improve public-gold top-1. This split result suggests that procedural fields are useful when extracted and matched reliably, while public-authored skills still require better normalization and semantic field matching.

The expected contribution is therefore not a claim that one provider or retriever is universally best. Instead, the thesis contributes a framework for analysing skill retrieval as an information-preservation problem, a benchmark for procedurally confusable skill retrieval, and empirical evidence about which fields and retrieval architectures help agents select the right procedural capability under scale.
