\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Large language model agents increasingly rely on reusable skills: procedural capability units that may package instructions, workflow steps, scripts, examples, resources, and constraints. As skill libraries scale, the central difficulty is not only storing many capabilities, but selecting the right capability when multiple skills appear semantically similar. A request about extracting information from a document, for example, may plausibly match skills for document review, summarisation, citation grounding, field extraction, or format conversion, even though these skills require different procedures.

This thesis investigates what information agent skill representations must preserve to distinguish semantically similar but procedurally distinct skills at scale. It separates three layers that are often conflated in prior work: the skill artifact, the selection representation, and the retrieval policy. It then evaluates retrieval strategies that use flat metadata, full skill artifacts, structured procedural fields, and hybrid dense-retrieval plus reranking methods on a benchmark designed to stress semantic confusability. Preliminary experiments use a library of 1006 skills, including 67 controlled core skills and a large background skill set, with retrieval accuracy, top-k recall, ranking quality, context cost, latency, and failure modes as evaluation dimensions.

Current results suggest that description-only retrieval is fragile under scale, while full-skill representations and structured procedural fields improve robustness. The strongest current method combines dense retrieval over full skill artifacts with structure-aware schema reranking, supporting the claim that semantic retrieval and procedural representation are complementary rather than interchangeable. The expected contribution is a clearer framework for analyzing skill-selection systems, a controlled benchmark for procedurally confusable skill retrieval, and empirical evidence about which representational information matters for scalable agent skill libraries.
