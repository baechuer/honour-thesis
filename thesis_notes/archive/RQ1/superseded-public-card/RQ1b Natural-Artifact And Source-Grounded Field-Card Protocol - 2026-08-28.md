## 1. Purpose And Evidence Boundary

RQ1 asks which operational information helps distinguish semantically close
but operationally distinct skills. The evidence is deliberately split:

| Study | Material | Intervention | Permitted conclusion |
|---|---|---|---|
| RQ1a | Controlled sibling skill cards | One skill-side field varies while non-target context is shared | A field has controlled causal discriminability/sufficiency. |
| RQ1b-N | Untouched public `SKILL.original.md` artifacts | None | Operational fields occur in natural skills and can be independently mapped as strict selection rationales; original-artifact selector results are naturalistic, not single-field causal deltas. |
| RQ1b-S | Source-grounded field-card derivative of the same public artifacts | Only the strict winner's locked field value is neutralised; a non-target sham edit is paired | The selector is sensitive to availability of that field in the stated field-card representation, conditional on passed fidelity controls. |

Neither RQ1b-N nor RQ1b-S proves a universal effect for unedited full public
documents. RQ1b-S is not I1/I2/I3/I3C, full-library retrieval, reranking,
graph/tree retrieval, task-success evaluation, or a replacement for RQ2.

## 3. RQ1b-N: Natural-Artifact Validation

For a strict family, use original sources unchanged. Independent blinded review
must establish: (a) one fully adequate skill for each prompt variant, or an
explicit acceptable-set/exclusion disposition; (b) the prompt clause requiring
the decisive operational information; (c) exact source evidence; and (d) one
primary-field classification or `MULTI_FIELD_OR_NONCODEABLE`.

Only strict-singleton, source-hash-valid families enter RQ1b-N strict Top-1.
Any multi-adequate item stays exploratory. Future selector outcomes are
original-artifact routing results and are never described as single-field causal
effects.

## 4. RQ1b-S: Field-Card Representation

### 4.1 Card construction

A field card is a derivative representation, not a rewritten source skill. It
uses anonymous candidate labels and this fixed schema:

```text
Use condition: <exact source excerpts, or NOT_STATED>
Input / precondition: <exact source excerpts, or NOT_STATED>
Output artifact: <exact source excerpts, or NOT_STATED>
Workflow / procedure: <exact source excerpts, or NOT_STATED>
Boundary / not for: <exact source excerpts, or NOT_STATED>
Dependency / resource: <exact source excerpts, or NOT_STATED>
Success / verification: <exact source excerpts, or NOT_STATED>
```

Each non-marker value must be an exact contiguous excerpt from that candidate's
hash-verified source. Titles, repository names, skill IDs, URLs, provenance,
and newly composed task summaries are excluded. `NOT_STATED` is allowed only
when independent review finds no source evidence for that slot. The card
deliberately does not claim to preserve the full artifact.

### 4.2 Three paired conditions

For every accepted pilot family, all candidates use the same schema and order:

| Condition | Change from source-grounded card |
|---|---|
| `field_card_original` | None. |
| `winner_target_field_neutralised` | Only the strict winner's locked field value becomes `NOT_SPECIFIED_FOR_THIS_FIELD`. |
| `winner_sham_field_neutralised` | Only the strict winner's pre-registered non-primary field value becomes the same marker. |

The marker is an explicit representation-level absence state, not prose claimed
to occur in the source. It is identical in target and sham conditions. No random
filler or token-length claim is used. The sham checks whether a change is
specific to removal of the target field rather than a generic missing-slot
effect.

### 4.3 Pilot acceptance gates

Each family must pass every gate before `FIELD_CARD_ABLATION_ELIGIBLE`:

1. **Lineage:** source hashes, candidates, prompts, and sealed strict gold match the frozen roster.
2. **Literal fidelity:** an independent auditor verifies every non-marker value as an exact source substring and finds no title, ID, source name, URL, or invented fact.
3. **Primary-field isolation:** the locked target is non-empty for the winner, at least one near-miss differs, and no direct or operationally equivalent target statement remains in another winner-card slot after target neutralisation.
4. **Sham validity:** a pre-registered non-empty winner field is non-primary and independently judged non-decisive for the frozen prompt requirement.
5. **Mechanical diff:** target and sham differ from original only in their designated value payload; headings, labels, order, all other slots, and all competing cards are byte-identical.
6. **Original-card route preservation:** two blinded reviewers inspecting the prompt and original field cards, without the sealed target, independently select the same unique fully adequate candidate as the sealed strict gold and reaffirm the locked field as the primary route-relevant field.
7. **Blind selection check:** two reviewers inspecting prompt plus target-neutralised cards cannot identify a unique candidate solely from a residual representation of the neutralised field.

The validation set passes only if at least four of six families pass every gate,
including `input_precondition` and `output_artifact`. Fewer than four, failure
of either required field, or any evidence-invention/title-leakage finding stops
scaling and requires a recorded methodological revision. A field-specific
failure limits the RQ1b-S stratum; it does not invalidate RQ1a.

## 5. Pilot Workflow

1. Materialise a private hash-checked packet per named family from P0. Packets
   contain anonymous source copies and schema instructions, but no prompt,
   gold, provenance, prior maps, scores, or results.
2. A local card builder returns one structured source-evidence card per
   candidate. It cannot infer absent fields from the prompt. Before submission,
   it may run the local literal validator only against its own JSON and its
   assigned anonymous source packet; this transcription preflight has no access
   to a prompt, gold label, provenance, another builder response, selector, or
   result.
3. A second independent local auditor checks fidelity and slot placement from
   the same anonymous sources without the builder response.
4. The coordinator validates both records and then unblinds only to register
   strict winner, locked target field, and a pre-registered sham slot.
5. A deterministic local materialiser writes the three conditions and a
   byte-level diff ledger. It never modifies `SKILL.original.md`.
6. Two blinded original-card reviewers verify that the derived card preserves
   the sealed strict route before any neutralisation is made.
7. Two blinded residual-cue reviewers inspect only target-neutralised cards.
8. The pilot report contains gate pass/fail and exclusion reasons only. It
   creates zero BM25, embedding, API, agent-selection, or thesis/PDF results.

At most six local reviewer agents may be active. Each works only on its assigned
local packet and is closed after auditing.

## 6. Post-Pilot Decision

If the acceptance rule passes, scale only with the same fail-closed gates and
freeze accepted cards before scoring. If it fails, stop and report whether the
blocker is incomplete source evidence, residual target evidence, invalid sham,
or strict-singleton preservation. Do not relax rules, infer missing facts, or
substitute selector results.
