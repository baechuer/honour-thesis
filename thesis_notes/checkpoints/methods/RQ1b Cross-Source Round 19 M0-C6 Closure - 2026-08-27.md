# RQ1b Cross-Source Round 19 M0-C6 Closure

Date: 2026-08-27

## Boundary

This checkpoint records local public-source curation, prompt cue control,
model-assisted blinded adequacy review, and strict-packet freezing. It is not
human annotation, a retrieval or representation experiment, embedding or
reranking evidence, an API result, a metric, or downstream-task success.

## M0 Through C1

- M0 collected 110 raw public GitHub leads, canonicalised them, and excluded
  five roots already represented in prior intake. The remaining Round 19
  intake contains 95 new roots.
- M1 commit-pinned public repositories and staged only `SKILL.md` originals
  plus repository metadata, without running source code. It retained 1,626
  canonical byte-verified originals from 51 origins. A missing repository
  licence is recorded as provenance only and is not an eligibility exclusion.
- M2 emitted source-only navigation metadata. C0A proposed 12 independent
  3-candidate compositions; this proposal stage did not claim peerhood.
- C0B read 36 exact originals in source packets and exact-validated 36
  evidence substrings. Eleven proposals were rejected for nonparallel,
  container/component, generic-specialist, lifecycle, adapter/interface, or
  otherwise asymmetric routes. One marketing-copy composition remained a
  source-backed draft.
- C1 passed the retained composition's exact source hashes, 3-candidate size,
  two-origin minimum, and no candidate reuse against earlier C6 manifests.

## C2 Through C6

- C2 drafted six direct/paraphrase prompt packets. C3 found one literal cue;
  that wording alone was rephrased, and the final literal audit passed 6/6.
  The manual C3 ledger marks every packet as high residual
  operational-context risk, so none can support an implicit-intent claim.
- C4 supplied anonymous candidate cards to two independent model-assisted,
  non-human reviewers. They agreed on a unique fully adequate card for four
  packets and disagreed on two because a second candidate was also judged
  fully adequate.
- The first automated C4 audit correctly failed closed on 14 nonliteral
  Markdown/line-break citations. A narrow citation-only repair substituted
  exact evidence from the same anonymous cards. It preserved reviewer IDs,
  methods, packet/card coverage, adequacy decisions, and rationales; the
  repaired C4 audit passed with four singleton agreements and two
  disagreements.
- C5 unsealed the card map and verified that each of the four agreements
  matches the sealed C2 construction target. C6 rechecked the C1/C3/C4/C5
  chain and froze four strict prompt packets from one candidate composition.
  The two disagreements remain outside strict top-1.

## Running Strict Curation State

The cumulative primary state is **30 frozen cross-source candidate
compositions, 192 strict direct/paraphrase prompt packets, and 5 unresolved
prompts**. These are curation and feasibility counts, not retrieval accuracy
or a result for any representation/retrieval strategy. The programme continues
with a discovery-first next cohort toward the predeclared minimum of 50
compositions; it must not weaken strict peer-route or singleton gates to reach
that number.
